# DeepSeek 候选方案校验修复设计

## 证据与目标

生产 `caa77e5` 的三端云验收通过 629 项断言，三个方案均保存为 `local-rule / invalid_provider_advice`。独立本地注入复现证明，数量正则将“进一步”“一致”“统一”“一旦”“一般风险”里的汉字误判为数量。云返回原文没有保存，三次回退的具体触发条件尚不能确认。现有提示也没有明确建议数量和文本长度上限。

目标是在原系统范围内修复可复现误判，并让下一次云验收能区分字段、数量和引用问题。采用经过正反例测试的精确词例屏蔽，保持剩余数量检测。完整语境数量解析或增加外部重试会扩大边界，暂不采用。

## 行为

仅修改工作流建议路径。数量检测在字符串副本中精确屏蔽 `进一步|一致|统一|一旦|一般风险`，返回文本保持原样。阿拉伯/Unicode 数字、其他中文数量、英文数量、百分比、时限、阈值继续拒绝；屏蔽词与数量混用仍拒绝。

结构化校验保留摘要非空且最多 4000 字符、建议 1–6 条且每条最多 1000 字符、引用非空且全部属于本次已知证据。提示明确这些约束，提供通过校验的定性 JSON 例子，要求使用原样证据 ID。

失败仍为 `local-rule / invalid_provider_advice`，可附 `validation_errors`。每项仅含固定 `code`、固定 `field`、可选建议 `index`，最多 12 项。不返回原文、匹配串、未知引用、密钥、请求或响应体。

权威 `risk` 对象仍完全从原模型证据复制；自然语言提案须由人核验。保留人工确认、角色权限、状态机、照片元数据与存储契约。无新数据库迁移、依赖、设备下发或模型训练。

## 发布与验收

在从 `caa77e5` 创建的隔离分支修复，避免离线力学实验进入生产。先测试和独立复审，再发布原 Render 服务。对照实际计划的 `advice.source` 与引用确认 DeepSeek 成功或具体降级原因。保存事件后实际重新部署，重新登录比对完整快照哈希。前端内容不变化，必要发布时仍使用既有安全静态文件集。

用户已授权自行设计、审查与实施；本设计完成自审，无未决字段或范围冲突。
