# 巷道分层顶板—锚固连接研究模块

版本：layered-roof-v1-20261019。对象为巷道顶板单位宽度双层条带。

## 求解对象与物理含义

两层分别使用小变形 Euler–Bernoulli 梁，各自两端简支，竖向向下为正。
每节点含位移和转角自由度；两层独立转角，不假设层间剪切粘结或整体组合截面。
层间相对位移 `g = w_lower - w_upper`，`max(g, 0)` 为模拟层间张开，单独区别于任一层挠度。

层间法向采用分布罚接触：`C_i = k_c Δx max(-g_i, 0)`，其中 `k_c` 单位为 N/m²，乘节点分担长度得到 N/m。
接触仅在受压时传力，`max(-g, 0)` 为有限罚刚度的弹性重叠，单独输出，不能作为离层。
内节点使用等长分担区间；端点相对位移固定为零，无接触能量。
锚固连接为零预紧轴向受拉弹簧：`T_i = k_t,i max(g_i, 0)`，单位 N。
下层另有接地线性等效支护弹簧。锚固拉力与接地支护反力分别输出。

总势能为 `Π = 1/2 uᵀ K₀ u + 1/2 Σ k_t max(g,0)² + 1/2 Σ k_c Δx max(-g,0)² - Fᵀu`。
阻尼 Newton 法与回溯线搜索求平衡。发布前逐帧检查自由度残差、总竖向力平衡和 `2U=Fᵀu`。
最后一个恒等式适用于本版本零预紧、零初始间隙的齐次分段线性模型。

输出包括两层位移与弯曲应力估计、节点层间张开、罚接触重叠、各连接拉力、下层支护反力、边界反力及数值核验量。
层间张开峰值为网格节点采样；应力与单层模型一致采用单元内 Hermite 曲率采样。

## 演示参数与工况

跨度8 m、宽1 m、24单元。上层厚0.6 m / E=12 GPa，下层厚0.3 m / E=6 GPa。
连接节点6/12/18，参考单连接刚度8 MN/m；下层节点12等效支护刚度2 MN/m。
接触刚度1e9 N/m²，连接预紧力0。

每工况21个准静态加载步，步数不对应现场时间。

| 工况 | 相对参考的设置 |
| --- | --- |
| 参考锚固 | 下层载荷q，上层0.2q；q=2..10 kN/m |
| 载荷增加 | 两层载荷均乘1.5，连接刚度不变 |
| 锚固连接刚度降低 | 同载荷，连接刚度降至参考的0.25 |
| 上层受载与层间接触 | 上层8q、下层0.1q，研究闭合接触 |

这组载荷是为研究张开/接触两类响应设定的等效载荷，不构成现场上覆岩层自重分配。
连接刚度降低表示等效连接柔化，当前未求解粘结滑移、屈服、断裂或锚杆索全长传力。
专业应用需岩层柱状图、边界与载荷来源、锚固参数、离层仪基点和监测曲线共同校准。

## AI与页面接入

登录后页面下方“把离层与锚固受力放在一起看”区域提供四工况、加载步、两层挠曲示意和数值对照表。
示意层间距与挠度显示倍率独立于计算结果，数值单位为mm/kN。
GET `/api/roof-risk/layered-roof` 返回经过校验的服务器预计算数据。
POST `/api/roof-risk/layered-roof/explain` 仅接受 `case_id`、整数 `step`；服务端选取计算证据和参考值后检索资料并调用已有建议服务。
企业/智库/管理员可发起解释，其他角色只读；切换工况清除旧解释，迟到响应不覆盖新工况。
沿用DeepSeek引用与数值内容校验，未配置或校验失败时明确返回规则回退。

本版本的解释是**已知预设工况对照**，还不是从现场监测反演异常来源的诊断器。
四工况的力学响应差异不作为异常识别准确率或预警提前量。
本模块独立于七特征XGBoost分类数据和工作流事件，研究解释不创建现场工单。

## 复现与验证

```powershell
python -m unittest discover -s tests/roof_mechanics -p test_layered_solver.py -v
python -m unittest discover -s tests/roof_mechanics -p test_solver.py -v
node --test tests/layered-roof.test.mjs
python tools/export_layered_roof.py --output "$env:TEMP/layered-roof-rebuilt.json"
```

导出器拒绝覆盖已有文件。新输出内容应与 `data/layered-roof-v1.json` 一致。
工件记录求解器、依赖单层求解器和导出器的LF规范化SHA-256，避免跨平台换行差异。
验证覆盖独立中心拉簧解析解、中心受压接触解析解、退化到单层解、接触网格收敛、对称性、守恒、输入拒绝，以及API权限、工件篡改和异步UI隔离。

专业参考：陈虎等，基于岩梁−块体理论的巷道软弱层直接顶板破坏形式研究，《岩土力学》2020，41(4):1447–1454，https://doi.org/10.16285/j.rsm.2019.0294 。该文支持岩梁建模的领域背景，本模块具体接触/连接模型与参数为工程演示设计。
